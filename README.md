   - Keys are strictly assigned to the user's email address to eliminate unauthorized key sharing.
2. **Private Master Administrator Control Panel:**
   - Dedicated tab to generate license keys for specific user emails with custom days and daily limits.
   - Visual dashboard to extend access (`+7d`, `+30d`, `+90d`), suspend/activate accounts, reset passwords, and export/import JSON database backups.
   - Separate, confidential Admin Operations Guide inaccessible to ordinary users.
3. **Dual AI Engine with User's Own Keys:**
   - Powered by Google Gemini (`gemini-2.5-flash`) & xAI Grok (`grok-2-vision-latest`).
   - Every user uses their own free API key for 100% data privacy and zero shared quota limits.
4. **Standalone EPS Vector Support:**
   - In-memory rasterizer extracts thumbnails directly from binary DOS EPS headers (No companion JPG needed).
5. **Safe Binary XMP/IPTC Embedding:**
   - Direct binary-safe 4-layer embedding into EPS (XMP, DSC, IPTC, TIFF) and JPG Exif via ExifTool.
6. **State & Scroll Preservation:**
   - Workspace state, loaded metadata, and scroll positions are automatically preserved across browser refresh.
